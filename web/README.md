# eSamithi Web

The office application for the browser (`https://app.esamithi.com`; QA host `https://console.esamithi.com/app/`).
Specification: [`docs/ESAMITHI-WEB-APP-REQUIREMENTS.md`](../docs/ESAMITHI-WEB-APP-REQUIREMENTS.md).

## Develop

```bash
cd web
npm install
npm run dev            # http://localhost:5173 — /api and /directory are proxied to the testbed
```

Sign in with a samithi join code (testbed: `TES-5155` → `admin` / `admin123`).
The dev proxy makes the app same-origin with the API, so the HttpOnly refresh cookie works on `localhost`.

## Scripts

| Script | Purpose |
|---|---|
| `npm run build` / `build:testbed` | production build (`/`) / QA build (`VITE_BASE=/app/`) |
| `npm run typecheck`, `lint`, `test` | gates run by CI (`.github/workflows/web.yml`) |
| `npm run test:e2e` | Playwright; set `E2E_SAMITHI_CODE` (and `E2E_BASE_URL` for a deployed host) |
| `npm run sync:i18n` / `check:i18n` | regenerate dictionaries from `src/renderer/src/i18n` / parity gate |
| `npm run fonts:build` | rebuild woff2 from `mobile/assets/fonts` |
| `node scripts/shoot.mjs <dir>` | login screenshots (needs Google Chrome) |

## Layout

```
src/app        router context + shell (Sidebar, TopBar, BannerStack, SessionDialog, UpdatePrompt)
src/routes     TanStack Router file routes (routeTree.gen.ts is generated by vite)
src/features   one folder per module: api / queries / schemas / components
src/components ui/ (owned shadcn-style primitives) + product components
src/lib        api (session manager, client, samithi resolver), i18n, format, theme, utils
src/styles     globals.css — design tokens (@theme), fonts, base rules
```

Rules: every user-visible string goes through `t()`; money is integer cents at the boundary; the SPA only calls
`${origin}/api/v1` and `${origin}/directory/`; no token is ever written to web storage.
